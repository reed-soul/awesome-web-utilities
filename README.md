# Awesome Web Utilities & Developer Resources

A curated list of useful online utility tools, developer resources, and web development links for everyday work.

Inspired by the awesome-list community.

## Online Utility Tools

- [AIOneTools](https://aionetools.com) – Collection of free online tools for text processing, calculators, converters, and simple generators.
- [ImgFlow](https://imgflow.taoliapp.com/en/) – Free in-browser image compressor and converter (HEIC/WebP/AVIF); files never leave your device.
- [TinyWow](https://tinywow.com) – Free PDF, image, writing, and file tools.
- [Designs.ai](https://designs.ai) – AI-powered tools for logos, videos, banners, and content creation.
- [Remove.bg](https://www.remove.bg) – Automatically remove image backgrounds.
- [ILovePDF](https://www.ilovepdf.com) – PDF editing and conversion tools.
- [Christmas Widget](https://aionetools.com/tools/holiday/christmas-countdown) - Christmas countdown widget for website

## Developer & Web Tools

- [CodePen](https://codepen.io) – Front-end playground for HTML, CSS, and JavaScript.
- [JSFiddle](https://jsfiddle.net) – Online code editor for testing snippets.
- [Postman](https://www.postman.com) – API development and testing platform.
- [JSON Formatter](https://jsonformatter.org) – Format and validate JSON data.

## Laravel & PHP Resources

- [Awesome Laravel](https://github.com/chiraggude/awesome-laravel) – Curated list of Laravel packages, tutorials, and resources.
- [Laravel Open Source Projects](https://github.com/goodnesskay/Laravel-Open-Source-Projects) – Real-world Laravel open-source applications.
- [Awesome PHP](https://github.com/ziadoz/awesome-php) – Comprehensive list of PHP libraries and frameworks.
